# Ch4oS Orchestration

Configuration, operating standards, and reusable agent designs for Codex-assisted development across Cha0sCollective projects.

This repository is the canonical design source for the organization's Codex operating model. Project repositories retain the effective `AGENTS.md` and `.codex/` configuration that Codex consumes for that project's exact revision.

The orchestration system is being introduced incrementally. Initial work defines the operating model, role boundaries, model-routing policy, review protocol, and per-project configuration conventions before any automated synchronization or deployment is enabled.
