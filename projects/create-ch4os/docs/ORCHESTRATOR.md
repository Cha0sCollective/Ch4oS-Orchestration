# Create: Ch4oS session guide

Start by verifying this is the Create: Ch4oS checkout, then record the branch,
`HEAD` and dirty state. Read the repository `AGENTS.md` and its required project
records: `docs/PRODUCT-CHARTER.md`, `docs/P0-BASELINE.md`,
`docs/DEPENDENCY-INCLUSION-POLICY.md` and `docs/CONTRIBUTING.md`; use
`docs/ENGINEERING-PRINCIPLES.md`, `install/README.md` and dated research only when
the packet needs them.

Confirm the active issue or explicit owner instruction, accepted base, scope,
installer pin, validation and owner gates. Do not infer a new packet from the latest
release or prior work. Create: Ch4oS owns gameplay, pack inputs and its installer
selection; Ch4oS-Installer owns installer behavior and the package contract.

Use the shared coordinator brief and routing records after this overlay is adopted.
Keep worker prompts small and source-based. Return proposed patches for coordinator
integration, and distinguish tests of the original snapshot from tests of a
separately constructed proposed patch. No local candidate is qualified merely by
appearing in the shared catalog.


The current coordinator owns scope, difficult reasoning, integration, verification
and final decisions. Preserve the existing Astra coordinator and independent
Sol review lane. Use the installed `ch4os-local-agents` MCP connector only when
its capabilities report a qualified profile for the bounded task. Supply explicit
paths, snapshot/candidate identity, budgets and acceptance criteria. Verify every
worker result. Missing capability escalates to Codex. OpenRouter also requires current endpoint terms suitable for the assignment, an approved free endpoint, host data permission and per-task consent. Qualification does not override service terms or authorize private data transmission.
The connector refers to a versioned host installation, not a sibling checkout.

Read `docs/CURRENT_WORK.md` at startup. Reconcile stale pointers against actual
Git and linked issue/PR state; surface competing assignments or missing authority.
At packet boundaries and before ending a session, replace obsolete pointer content
and keep it under roughly 500 words. Detailed history belongs in durable records.

Use this startup prompt in a fresh chat:

> Act as this project's production coordinator. Read AGENTS.md,
> docs/ORCHESTRATOR.md, and docs/CURRENT_WORK.md. Verify the current repository
> and linked work state, then continue the next authorized bounded packet.
> Use qualified local workers where appropriate and verify their results.

This guide does not claim activation of a saved subagent profile.
