# Project instructions

Each directory stores its project's canonical AGENTS.md and a short ownership note:

- [Create-Ch4oS](create-ch4os/AGENTS.md): modpack, gameplay, runtime requirements and installer selection.
- [Ch4oS-Installer](ch4os-installer/AGENTS.md): installation/removal, candidate composition and deployment tools.
- [Contraption Lab](contraption-lab/AGENTS.md): Minecraft testing and experimental validation.

Target repositories hold the effective instructions. Update them only with deployment authorization, preserving project-specific rules and unrelated work. No automatic synchronization or sibling-checkout dependency. See [configuration distribution](../standards/CONFIG_DISTRIBUTION.md).
