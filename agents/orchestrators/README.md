# Orchestrators

Orchestrators own a bounded work packet. They recover the real project state,
route separable work, integrate results, keep affected documentation true and
deliver an exact candidate for review. They do not need to make every edit.

The current coordinator brief is [coordinator.md](coordinator.md). Routing records
live under [routing/](routing/README.md). A routing record describes an available
or candidate model; it does not create a saved profile or qualify the model for a
role.
