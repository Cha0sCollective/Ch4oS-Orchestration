# Optional shared agents

The coordinator can work directly. Use an agent only for a bounded job that benefits from separate work; send only the relevant context.

- [repo-explorer.toml](repo-explorer.toml): optional read-only fact gathering, Terra Medium.
- [independent-reviewer.toml](independent-reviewer.toml): fresh, read-only review, Sol High. Required for substantive behavior, security-sensitive and operating-rule changes; not routine documentation or mechanical edits.
- [experiment-specialist.md](experiment-specialist.md), [documentation-steward.md](documentation-steward.md), and [publication-steward.md](publication-steward.md): optional design references, not a standing roster or extra approval lanes.

The TOMLs are canonical sources for project-local copies. Verify actual model, effort and permissions when using a profile. Follow [model routing](../standards/MODEL_ROUTING.md) and [review guidance](../standards/REVIEW_PROTOCOL.md).
